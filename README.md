1. Ввод ширины
2. Ввод высоты
3. Кнопка «Вычислить», при нажатии на которую сначала проводится проверка на наличие данных в полях (обратите внимание, что в поля можно вносить только числовые значения) затем находится произведение ширины на высоту и отображается результат в формате «S = ширина * высота = результат
4. Вывести всплывающую подсказку об успешном вычислении.
