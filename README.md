# laboratornaya4

Реализовать верстку по макету:

1.Экран должен скролиться.

2.Добавить любой длинный текст.

3.Цвет верхней панели и иконок – зеленый. 

4.Цвет сердечка – красный.

## Задания для выполнения

1.Реализовать приложение по макету из задания. 

2.Реализовать кнопку нажатия на сердце. 

3.Реализовать функционал нажатия на кнопки «Позвонить», «Маршрут», «Поделиться».
